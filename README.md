# ClinicalData_Linkoping

This repo contains clinical data used in Saremi et al. (2025) for the three groups: normal hearing, noise-induced hearing loss (NIHL), and presbyacusis. The files report the audiograms, as well as the test scores for HINT, reading span, PTC, DPOAE, and ABR.

The repo also contains the MATLAB implementation of the computational model to reproduce Fig. 8 of the paper.
